# Setting the clock on the Siemens oven

## The short version

Press the clock (`0`) icon **four times**. Don't stop at the first press.

## Why it's confusing

The clock icon cycles through four separate functions:

| Press | Function |
| ----- | -------- |
| 1st   | Short-term timer (the alarm — this is where you keep getting stuck) |
| 2nd   | Cooking duration |
| 3rd   | End time |
| 4th   | **Time of day** ← the one you want |

Presses 2 and 3 may do nothing when the oven is off, since duration and end
time only appear with a heating function selected. In that case the time of
day can turn up on the second press instead. Either way: keep tapping until
the **time itself** flashes, rather than a bell/timer symbol.

## Steps

1. Oven off. No cooking duration or end time set, or the clock won't accept changes.
2. Tap the clock (`0`) icon until the time flashes (see table above).
3. Set it with `−` and `+`. 24-hour format.
4. Take your finger away. It's accepted automatically after a few seconds.

## If you end up in the `c1 … c7` menu

You held the clock icon instead of tapping it. A ~4 second hold on `0` opens
Siemens' *Grundeinstellungen* (basic settings) menu. Nothing is broken.

- `c1` — clock display setting (can hide the time entirely — the usual
  culprit if the clock "disappears")
- `c2` — signal tone duration
- `c3` — waiting time before a setting is accepted
- `c4`–`c7` — unconfirmed, model-specific

Browse with `0`, change values with `−`/`+`, hold `0` ~4s to save.

**To get out without changing anything:** don't touch `−`/`+`. Let it time
out, or switch off at the fuse for 10 seconds.

## Panel legend

- `0` / clock — timer and clock functions (tap = cycle, hold = basic settings)
- `−` / `+` — adjust value
- key — child lock (hold ~3s). Timer and clock can still be set while active.
- `kg` — automatic weight-based cooking programme. Nothing to do with the clock.
